# trptc

Sum, multiply, subtract, divide and power two values.

```python
from trptc import divide, multiply, power, subtract, sum

sum(2, 3)  # 5
multiply(2, 3)  # 6
subtract(5, 3)  # 2
divide(6, 3)  # 2.0
power(2, 3)  # 8
```

## Install

```
uv add git+https://github.com/BalthazarApp/trptc
```

Or, from a clone:

```
uv sync
```
